关于本站

2026 年 10 月 18 日

这个站只写一件事：当 AI Agent 真正跑在生产里，你怎么知道它做对了、花了多少钱、卡在哪里。不是模型评测，不是提示词技巧，是可观测性、成本与运维——那些把 demo 推上线之后才会遇到的问题。

写什么

  • 可观测性：Trace、Metrics、Evaluation 三大支柱怎么落到 Agent 上，为什么传统 APM 看不见"做错了"。
  • Trace 的语义：一条 Agent 行为树到底长什么样，OpenTelemetry GenAI 语义约定怎么读。
  • 评估：从规则打分到 LLM-as-a-Judge，怎么给"对不对"一个可复现的分数。
  • 成本：token 花在哪、什么情况下会悄悄失控、自托管和 API 的账怎么算。
  • 选型：可观测性工具的实际版图，以及端到端落地时的取舍。

写给谁

写给正在把 Agent 送上生产的人：需要向老板解释这个月账单为什么涨了三倍，需要回答"它昨天为什么答错了"，需要在几个方案之间做选择并承担后果。文章假设你会读日志、看得懂代码，但不假设你已经踩过所有坑。

怎么写的

尽量一手、可复现：能贴出真实的 trace 结构就不画示意图，能给出具体公式就不写"成本会显著上升"。涉及厂商能力与价格时，以官方文档为准并标注时间——这个领域的数字变化很快，一个半年前的结论可能已经不成立。
