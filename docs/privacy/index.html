隐私政策

2026 年 10 月 18 日

本站是 ezaiops.com 上的一个静态博客，托管在 GitHub Pages。它没有账号系统、没有评论、没有订阅表单，也没有任何会把你输入的内容发出去的交互。这份政策说明的，主要是托管方日志和广告 Cookie 这两件我们无法完全避免的事。

本站会接触到的数据

页面由 GitHub Pages 提供。和任何网站托管商一样，GitHub 会记录请求（IP 地址、User-Agent、请求的 URL、时间戳），用于提供服务并防止滥用。我们不会把这些日志作为数据集接收，不会与其他信息合并，也不会用它们识别访客。具体处理方式见 GitHub 的隐私声明。

除此之外，本站不设置任何用于识别你的 Cookie，也不收集邮箱、姓名或任何表单数据。

Cookie 与广告

本站目前没有启用广告。未来可能接入 Google AdSense：启用后，Google 及其合作伙伴会使用 Cookie 或网络信标，基于你此前访问本站及其他网站的情况投放广告。

你可以随时在 Google 广告设置中退出个性化广告，或在 aboutads.info 退出第三方供应商的 Cookie。对欧洲经济区、英国和瑞士的访客，法律要求先取得同意：启用广告后，会在设置任何广告 Cookie 之前显示同意提示，你也可以随时通过提示中的链接更改选择。

统计分析

目前没有部署任何统计工具。如果未来启用，只会使用聚合的、非识别性指标（页面浏览量、来源、国家/地区级别的位置），并在生效前更新本页。

你的权利

由于本站不收集你的内容、也没有账号，通常并不存在可供提供或删除的个人数据。如果你认为我们持有关于你的信息——例如你发来的一封邮件或一条 issue——可以要求查看、索取副本或要求删除，通过联系页提出即可。请求会尽力处理，不需要注册。

外部链接

文章会链接到 GitHub、各家模型厂商文档以及姊妹站 tools.ezaiops.com。离开本站后，你的数据适用目标网站的政策，本页不覆盖它们。

儿童隐私

本站面向从事 AI 工程与运维的从业者，不面向 13 岁以下儿童，也不会主动收集儿童信息。

政策变更

实质性变更——启用广告、增加统计、加入任何会把数据传出你设备的特性——都会反映在本页，并更新页面顶部的日期。本站没有邮件列表可通知，因此本页即为记录。

联系我们

对本政策有疑问，请通过联系页提出。
