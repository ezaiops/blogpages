纠错、选题建议、合作咨询都欢迎。GitHub 是唯一渠道：没有支持邮箱，没有工单系统，也没有在线客服——这个站是静态的，没有后端来跑这些。

内容纠错

这是最有价值的一类反馈，会优先处理。请尽量附上：

  • 出错的页面与具体段落。
  • 你认为正确的说法，以及支撑它的来源（官方文档、规范、可复现的 trace 或代码）。
  • 如果涉及价格或厂商能力，注明你核对的日期——这类信息时效性很强。

选题建议

说你正在被什么问题卡住，比说"写写 XX 吧"有用得多。如果某个问题在多个团队里反复出现，它通常值得写一篇。

广告与合作

展示广告通过 Google AdSense 投放，没有可谈的空间。文章里不做带赞助的排序或推荐；如果未来出现赞助内容，会明确标注。

隐私相关问题

同样通过 GitHub 提出。本站的隐私政策说明了收集什么、不收集什么。

响应时间

尽力而为，没有服务承诺。纠错通常几天内处理；选题建议会按"有多少人真正需要"来排。如果文章里的结论已经明显过时，请在标题里写清楚，会往前排。
