# ezaiops.com — AI Agent & LLMOps field notes

Static blog served from `docs/` on GitHub Pages at **https://ezaiops.com**.
Chinese at the root, English under `/en/`.

## Structure

```
docs/
  index.html                     Chinese home
  en/index.html                  English home
  posts/<slug>/index.html        Chinese post
  en/posts/<slug>/index.html     English post
  about/  contact/  privacy/     Static pages (both languages)
  sitemap.xml  robots.txt  ads.txt
scripts/
  generate_sitemap.py            rebuilds docs/sitemap.xml
  build_static_pages.py          rebuilds about/contact/privacy
```

Each page carries its own `<style>` block — there is no shared stylesheet. The
`<head>` of every page declares canonical plus `zh-CN` / `en` / `x-default`
hreflang alternates.

## Adding a post

1. Create `docs/posts/<slug>/index.html` and `docs/en/posts/<slug>/index.html`,
   copying the head, header, article and footer from an existing post.
2. Link both from the matching home page (`#featured` or `#topics`).
3. Regenerate the sitemap:
   ```bash
   python scripts/generate_sitemap.py
   ```
   It walks `docs/**/index.html`, pairs the zh/en pages by path, and emits
   `xhtml:link` alternates with `lastmod` taken from each file's last git commit.

## Editing the static pages

`about/`, `contact/` and `privacy/` are generated by `scripts/build_static_pages.py`
so the six pages stay consistent. Edit the copy in that script, then run it:

```bash
python scripts/build_static_pages.py
```

It also adds the About · Contact · Privacy links to the footer of every page
that lacks them, which is why new posts pick them up automatically.

## Deploy

Push to the `blog` branch. GitHub Pages serves `docs/` and the `CNAME` file binds
`ezaiops.com`. The `post-commit` hook pushes automatically.

## Notes

- Links to the sister site **tools.ezaiops.com** carry `?lang=zh` or `?lang=en`
  so readers land in their own language.
- `ads.txt` is a commented-out placeholder — uncomment with the AdSense
  publisher ID when ads go live.
